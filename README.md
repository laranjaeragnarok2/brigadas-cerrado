## 🍃 Sobre o Projeto

O **CerradoVigil** (Brigadas do Cerrado Vivo) é uma iniciativa tecnológica e comunitária criada para fortalecer o combate a incêndios florestais no coração do Brasil. A plataforma conecta moradores, turistas, doadores e brigadistas voluntários das regiões da **Chapada dos Veadeiros, Cavalcante, Quilombo Kalunga, Pirenópolis e Mambaí**.

Inspirada na estética da paisagem goiana e com suporte a funcionamento offline, a plataforma garante legibilidade, rapidez e facilidade de uso mesmo em áreas de sinal de celular fraco ou inexistente.

🔗 **Link Direto da Aplicação Ao Vivo:** [https://laranjaeragnarok2.github.io/brigadas-cerrado/](https://laranjaeragnarok2.github.io/brigadas-cerrado/)

## 🌟 Principais Recursos

### 📍 Mapeamento & Alertas da Comunidade ("Waze do Cerrado")
- **Reporte Rápido com Auto-GPS:** Envio de alertas de *Fogo Ativo*, *Coluna de Fumaça* ou *Rescaldo* com captura de coordenadas automática via satélite.
- **Mapa Interativo (Satélite Esri + Leaflet):** Visualização em tempo real de focos de calor com camada de satélite de alta resolução e geoserviços WMS do **INPE TerraBrasilis**.
- **Evidência Fotográfica:** Envio de imagem da ocorrência direto da câmera do celular.
- **Sincronização em Tempo Real (Supabase):** Relatos registrados são salvos e compartilhados instantaneamente via banco de dados Supabase PostgreSQL na nuvem.

### 🤝 Apoio Direto & Transparência
- **Doações Diretas via PIX:** Apoio financeiro direto para a conta oficial de cada brigada comunitária, sem intermediários ou taxas.
- **Selo de Verificação INPE:** Destaque para brigadas verificadas em campo e barras de progresso financeiro de arrecadação.

### 🚨 Modo Emergência SOS & Offline (PWA)
- **Central de Emergência SOS:** Acesso direto em 1 clique ao botão SOS com coordenadas de resgate em destaque para envio rápido aos bombeiros.
- **Discagem Direta:** Números de emergência salvos offline (193 Corpo de Bombeiros, Prevfogo IBAMA 0800, 199 Defesa Civil).
- **Protocolo de Segurança em 3 Passos:** Guia visual de sobrevivência em caso de cerca por fumaça na serra.

## 🚀 Como Rodar Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/laranjaeragnarok2/brigadas-cerrado.git

# 2. Entrar na pasta
cd brigadas-cerrado

# 3. Instalar as dependências
npm install

# 4. Iniciar o servidor local
npm run dev

# 5. Fazer deploy no GitHub Pages
npm run deploy
```

Abra o navegador em `http://localhost:5173`.
